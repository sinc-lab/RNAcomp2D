# FASTA examples

In this folder you can find some examples of FASTA files for RNAcomp2D. You can
download them to your system and use them for testing or check the expected format.

If you only want to submit a sequence and compare structures generated by the
methods available in RNAcomp2D, you can see `examples/sequence.fasta`.

If you want to compare against a reference structure, you can name your
sequence as "Reference" and provide a file like `examples/reference.fasta`.

If you want to compare results of other methods, you can name your sequence as
the method used and upload a file like `examples/other_methods.fasta`.

You can also format your file like `examples/reference_and_other_methods.fasta` 
to compare your results and the available methods against a reference structure.
